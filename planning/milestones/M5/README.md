# M5: Public launch, first-48h observability and product learning (EPIC-0001)

**Status:** `todo`. **Entry:** M4 source-truth/privacy/read-only and release decision foundations must be verified; public rollout still follows ZeroSpoils's own legal/store/build/owner gates. **Epic:** [EPIC-0001](../../epics/EPIC-0001-beta-to-public-launch-operations.md).

## Objective

Grow the same beta cockpit into a public-launch control room for staged Apple/Google rollout, the first 48 hours, weekly learning, privacy-safe food-waste outcomes and future commercial experiments. Do not present planned subscriptions, household sync, recipes, food-quality features or referral rewards as already live.

## Included workitems

- [WI-0017](../../workitems/WI-0017-public-launch-staged-rollout-first-48h.md) — Run staged public-launch and first-48h operations cockpit (P1)
- [WI-0018](../../workitems/WI-0018-retention-food-waste-value-and-learning.md) — Analyze real retention, food-waste outcomes and feature value by cohort (P1)
- [WI-0019](../../workitems/WI-0019-growth-referral-pro-monetization-forecast.md) — Report consented acquisition, referral and Pro monetization when available (P2)

## Stage gates

1. **Public readiness (0017):** real store/submission/release evidence, Crashlytics/incident/consent status, manual checks, pause/rollback rehearsal and owner signoff; browser view has no privileged rollout action.
2. **Product outcomes (0018):** compute D1/D7/W4 correctly for eligible consented cohorts; show actual item-use/discard outcomes and uncertainty. A usage event is not proof of avoided food waste or cash saved.
3. **Growth/Pro (0019):** optional later views only after valid campaign/referral, entitlement and billing sources exist. Free launch does not imply revenue or active paid tier.

**Exit:** first-48h report and first-week launch pack link to original evidence, failed/missing integrations are visible, every decision has an owner, and product/growth claims are not fabricated.
